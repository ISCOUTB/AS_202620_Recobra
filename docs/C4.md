# C4 - Contexto, nivel 1 - Recobra
 
En este nivel representamos a Recobra como un único sistema y mostramos quién interactúa con él desde afuera.
 
## Personas
 
**Usuario que perdió un objeto**
Usa Recobra para registrar objetos perdidos, consultar publicaciones y recibir notificaciones sobre posibles coincidencias.
 
**Usuario que encontró un objeto**
Usa Recobra para registrar objetos encontrados y ayudar a que su propietario los identifique.
 
**Administrador**
Supervisa las publicaciones, gestiona situaciones problemáticas y consulta la trazabilidad del sistema.
 
## Sistema
 
**Recobra**
Gestiona publicaciones de objetos perdidos y encontrados, hace búsquedas y coincidencias, genera notificaciones y mantiene la trazabilidad del ciclo de vida de cada objeto.
 
## Sistema externo
 
**Servicio de notificaciones**
Envía los avisos a los usuarios cuando se detecta una coincidencia u otro evento relevante. Qué pasa si este servicio falla está cubierto en el escenario S4a de `escenarios_calidad.md`.
 
## Relaciones
 
- Usuario que perdió un objeto → publica y consulta → Recobra
- Usuario que encontró un objeto → publica → Recobra
- Administrador → supervisa → Recobra
- Recobra → envía avisos → Servicio de notificaciones

# C4 — Contexto, nivel 1 — Recobra

Para el C4 de contexto se representa a Recobra como un único sistema, mostrando los actores externos que interactúan con él.

## Personas

**Usuario que perdió un objeto**
Utiliza Recobra para registrar objetos perdidos, consultar publicaciones y recibir notificaciones sobre posibles coincidencias.

**Usuario que encontró un objeto**
Utiliza Recobra para registrar objetos encontrados y facilitar que su propietario pueda identificarlos.

**Administrador**
Supervisa las publicaciones, gestiona situaciones problemáticas y consulta la trazabilidad del sistema.

## Sistema

**Recobra**
Plataforma encargada de gestionar publicaciones de objetos perdidos y encontrados, realizar búsquedas y coincidencias, generar notificaciones y mantener la trazabilidad del ciclo de vida de los objetos.

## Sistemas externos

**Servicio de notificaciones**
Servicio utilizado para enviar avisos a los usuarios cuando se detectan coincidencias o eventos relevantes. Su comportamiento en caso de falla está cubierto por el escenario S4a en `escenarios_calidad.md`.

## Relaciones

- Usuario que perdió un objeto → publica y consulta → Recobra
- Usuario que encontró un objeto → publica → Recobra
- Administrador → administra / supervisa → Recobra
- Recobra → envía avisos → Servicio de notificaciones

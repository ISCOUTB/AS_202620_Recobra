# C4-C1: Diagrama de Contexto — Recobra

Muestra a Recobra como una caja única y quiénes interactúan con ella: los
usuarios del campus, el administrador y los sistemas externos planeados
(proveedor de correo o push, directorio institucional).

```mermaid
flowchart LR
    usuario["Usuario del campus<br/><i>Persona</i><br/>Pierde o encuentra un objeto"]
    admin["Administrador<br/><i>Persona</i><br/>Modera publicaciones y reclamos"]
    recobra["Recobra<br/><i>Sistema de software</i><br/>Centraliza, empareja y notifica objetos perdidos/encontrados"]
    notif["Proveedor de correo o push<br/><i>Sistema externo</i><br/>Canal adicional de avisos — planeado"]
    auth["Directorio institucional UTB<br/><i>Sistema externo</i><br/>Alternativa futura de inicio de sesión (ADR-0013)"]

    usuario -->|"Publica objetos, consulta coincidencias (HTTPS)"| recobra
    admin -->|"Modera publicaciones, resuelve reclamos (HTTPS)"| recobra
    recobra -.->|"Enviaría avisos fuera de la app — no integrado (API/HTTPS)"| notif
    recobra -.->|"Validaría la identidad — no integrado (OIDC/HTTPS)"| auth

    classDef persona fill:#08427b,color:#fff,stroke:#052e56;
    classDef sistema fill:#1168bd,color:#fff,stroke:#0b4884;
    classDef externo fill:#999999,color:#fff,stroke:#6b6b6b;

    class usuario,admin persona;
    class recobra sistema;
    class notif,auth externo;
```

**Leyenda:** azul oscuro = persona · azul = sistema Recobra · gris = sistema externo.
Las etiquetas de las flechas indican la acción y el protocolo.
Las notificaciones ya existen **dentro** de Recobra como bandeja de avisos
([ADR-0015](../adr/0015-notificaciones-en-la-aplicacion.md)); el proveedor de correo o push
queda como canal futuro, por eso su flecha es discontinua. La autenticación ya existe, pero **dentro**
de Recobra: cuentas con correo `@utb.edu.co` y sesiones propias
([ADR-0013](../adr/0013-cuentas-con-correo-institucional-y-sesiones-opacas.md)); el directorio
institucional queda como alternativa futura, por eso su flecha es discontinua (ver [`docs/context-map.md`](../context-map.md) para
el detalle de contextos delimitados).

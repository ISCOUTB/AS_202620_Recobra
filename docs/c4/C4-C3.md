# C4-C3: Diagrama de Componentes — API Recobra

Hace zoom sobre el contenedor **API backend (NestJS)** del [C4-C2](C4-C2.md),
mostrando los componentes internos que implementan la arquitectura hexagonal
(dominio, aplicación, adaptadores) descrita en
[`docs/arc42/arc42.md`](../arc42/arc42.md#5-bloques-de-construcción).

```mermaid
flowchart LR

        direction LR
        controller["PublicacionesController<br/><i>Adaptador HTTP entrante</i><br/>src/publicaciones/"]
        filtro["PublicacionInvalidaFilter<br/><i>Adaptador HTTP</i><br/>traduce errores de dominio a 400"]
        crear["CrearPublicacion<br/><i>Caso de uso</i><br/>src/application/use-cases/"]
        consultar["ConsultarPublicacion<br/><i>Caso de uso</i><br/>src/application/use-cases/"]
        entidad["Publicacion<br/><i>Entidad de dominio</i><br/>src/domain/entities/"]
        puerto["PublicacionRepository<br/><i>Puerto de salida</i><br/>src/domain/ports/"]
        adaptador["MemoriaPublicacionRepository<br/><i>Adaptador de persistencia</i><br/>src/infrastructure/persistence/"]
        salud["SaludController<br/><i>Adaptador HTTP</i><br/>src/salud/ — GET /health"]
    end

    store[("Persistencia en memoria<br/><i>objetivo: PostgreSQL</i>")]

    cliente -->|"HTTP/JSON"| controller
    controller --> crear

    controller -.-> filtro
    crear --> entidad
    consultar --> entidad

    puerto -.->|"implementado por"| adaptador

    cliente -->|"GET /health"| salud

    classDef contenedor fill:#438dd5,color:#fff,stroke:#2e6295;

```

**Leyenda:** azul (contenedor) = App cliente Flutter, fuera del zoom · azul claro
= componente dentro de la API · gris = almacén de datos. Flecha punteada =
relación de implementación de puerto/adaptador, no de llamada directa.

Cada componente corresponde a un bloque de la sección 5 de
[`docs/arc42/arc42.md`](../arc42/arc42.md#5-bloques-de-construcción); la
propiedad de los datos que maneja `PublicacionRepository` está detallada en
[`docs/modulo-datos.md`](../modulo-datos.md).

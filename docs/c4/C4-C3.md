# C4-C3: Diagrama de Componentes — API Recobra

Hace zoom sobre el contenedor **API backend (NestJS)** del [C4-C2](C4-C2.md),
mostrando los componentes internos que implementan la arquitectura hexagonal
(dominio, aplicación, adaptadores) descrita en
[`docs/arc42/arc42.md`](../arc42/arc42.md#5-bloques-de-construcción).

Actualizado para el segundo corte (S10): incluye la búsqueda con filtros, el
contexto de Emparejamiento, la observabilidad y el adaptador PostgreSQL.

**Leyenda:** azul = contenedor fuera del zoom · azul claro = componente dentro
de la API · gris = almacén de datos. Flecha punteada = implementación de
puerto o evento, no llamada directa.

**Regla de dueño de datos:** Emparejamiento nunca escribe sobre la tabla de
publicaciones; solo la lee a través del puerto `PublicacionRepository` (ver
[`docs/modulo-datos.md`](../modulo-datos.md) y la auditoría en
[`docs/auditoria-generacion-ia.md`](../auditoria-generacion-ia.md)).

Cada componente corresponde a un bloque de la sección 5 de
[`docs/arc42/arc42.md`](../arc42/arc42.md#5-bloques-de-construcción).

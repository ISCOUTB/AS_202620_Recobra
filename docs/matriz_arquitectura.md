# Matriz comparativa de alternativas arquitectónicas

| Criterio | Capas | Hexagonal | Monolito modular |
|---|---|---|---|
| Separación de responsabilidades | Media | Alta | Alta |
| Facilidad de pruebas | Media | Muy alta | Alta |
| Acoplamiento | Medio | Bajo | Bajo |
| Complejidad | Baja | Media | Baja |
| Escalabilidad | Media | Alta | Media |
| Mantenibilidad | Media | Muy alta | Alta |

## Decisión

Se adopta una **arquitectura hexagonal implementada como monolito modular** porque ofrece un buen equilibrio entre mantenibilidad, pruebas y simplicidad para un proyecto académico.
